Five phases: Concept & Scope → Core Identity → Scenario & Greetings → Examples & Lore → Finalize. Design values: round-trip fidelity of concept data in exported cards, additive changes that leave existing entry points untouched, non-LLM components for pure logic to save tokens, `ThreadPoolExecutor` parallelism in later phases, and never emitting raw card JSON in chat — card writes go through tool calls. In-flight work has included orthogonal `card_type` (persona/agent) and `output_format` (chara_card_v2/markdown_prompt) dimensions.
